# Contributing to Wren

Thank you. Wren stays small, readable, and honest.

## Rules that do not move

1. Offline is the default. A network call is a user-visible Yes/No.
2. No silent clicks, keystrokes, or clipboard writes.
3. New watchers (OCR, accessibility trees, screenshots) are opt-in in `config.json`.
4. Keep Python modules short enough to audit in one sitting.

## Good first patches

- gtk4-layer-shell always-on-top on KDE and GNOME
- Hyprland / Sway active-window helpers in `watch.py`
- Piper voice presets
- A 1B-model system prompt tuned for 8 GB machines
- Tests for `brain._parse`

## How to send work

Fork, branch, pull request. Describe the machine you tested (CachyOS, Bazzite, other) and the RAM size.
